/create-prompt Create a prompt named module-review. This prompt will take a file as an input and reviews the source and header (.c and .h) of that module against the default c instructions. Use the Embedded C Expert agent and review the file from the expert point of view. As the result, point out or the potential bugs, any instruction violation or any best practices that could be applied to the selected module. The user either will provide the module by selecting header or the source file or simply puts the name of the module in the prompt. Give the result as a list. Then ask user if they want you to carry on and modify the file based on the result entries.
